Fit global co-occurrence evidence with word vectors

Predict log co-occurrence counts, measure weighted squared error, and follow PyTorch's full-batch gradients into an Adagrad update.

Start with the separate intuition lesson for the reasoning. Here, pick an observed cell and inspect its actual calculations alongside the Python source. Selecting a cell does not turn this full-batch algorithm into single-pair SGD.

Log means base e. This chapter uses the supplied ice, water, steam, cats, and dogs corpus, not the earlier pets/fruit/vehicles corpus. Its loss values are not directly comparable with either Word2Vec objective.

3. Connect the objective to the gradients

    

      
Define a prediction for an observed count

      
Let \(w_i\) be the target embedding, \(u_j\) the context embedding, \(b_i\) the target bias, and \(c_j\) the context bias. Both embedding tables are \(V \times D\); both bias tables are \(V \times 1\). They are distinct even though this corpus produces a symmetric count matrix.

      
\[\begin{aligned}y_{ij} &= w_i^\top u_j + b_i + c_j\\t_{ij} &= \log(X_{ij})\\r_{ij} &= y_{ij} - t_{ij}\end{aligned}\]

      
The prediction is a real-valued log count. \(\exp(y_{ij})\) maps it back to a count scale, but not to a normalized probability. Biases are learned offsets; they are not hard-coded word-frequency logarithms.

      
Weight the squared residual, then average the batch

      
The set \(\Omega\) contains only cells with \(X_{ij} > 0\). Here \(M = |\Omega| = 80\). A zero cell has no log target; it is not assigned a zero regression target.

      
\[f(X)=\begin{cases}(X/10)^{0.75}, & X < 10\\1, & X \geq 10\end{cases}\]\[L=\frac{1}{M}\sum_{(i,j)\in\Omega} f(X_{ij})r_{ij}^{2}\]

      
The mean differs from the original paper's commonly written sum by a constant factor. All derivatives below include \(1/M\) because this implementation calls .mean(). Its \(f(X)\) is fixed data, not a trainable parameter.

      
Start backward with sensitivity to one prediction

      
The derivative of \(r^2\) is \(2r\), and \(r\) changes one-for-one with \(y\). Define \(a_{ij}\) as this cell's contribution to the mean loss's prediction gradient:

      
\[a_{ij}=\frac{\partial L}{\partial y_{ij}}=\frac{2f(X_{ij})r_{ij}}{M}\]

      
If prediction exceeds target, \(r\) is positive and lowering \(y\) is locally helpful. If prediction is too small, \(r\) is negative and raising \(y\) is locally helpful. The output is not passed through a sigmoid; this is squared-error regression, not binary classification.

      
Sum contributions wherever a parameter is shared

      
A target vector is reused by every observed cell in its row. A context vector is reused by every observed cell in its column. Each gets the sum of the corresponding chain-rule contributions:

      
\[\begin{aligned}\frac{\partial L}{\partial w_i} &= \sum_{j:(i,j)\in\Omega} a_{ij}u_j\\\frac{\partial L}{\partial u_j} &= \sum_{i:(i,j)\in\Omega} a_{ij}w_i\\\frac{\partial L}{\partial b_i} &= \sum_{j:(i,j)\in\Omega} a_{ij}\\\frac{\partial L}{\partial c_j} &= \sum_{i:(i,j)\in\Omega} a_{ij}\end{aligned}\]

      
loss.backward() obtains these gradients by following the graph of PyTorch tensor operations. optimizer.zero_grad() removes gradients left from a prior pass. Neither operation changes the model weights or resets Adagrad's accumulator.

      
Apply Adagrad, not plain gradient descent

      
For each scalar parameter \(\theta\), the optimizer has its own squared-gradient history \(A\). With this run's defaults:

      
\[\begin{aligned}A_{\mathrm{new}} &= A_{\mathrm{old}} + g^2\\\theta_{\mathrm{new}} &= \theta_{\mathrm{old}}-\frac{0.03g}{\sqrt{A_{\mathrm{new}}}+10^{-10}}\end{aligned}\]

      
\(A\) starts at zero; epsilon is added after the square root. Weight decay and learning-rate decay are zero. A first nonzero gradient can therefore produce a step near 0.03 regardless of its magnitude; later steps depend on that parameter's accumulated history. This is not Adam, and there is no moving-average decay.

Co-occurrence counts define the evidence; log counts define the regression targets; \(f(X)\) controls influence; autograd measures shared-parameter sensitivities; Adagrad changes parameters using accumulated history. Similarity is a separate use of the resulting vectors, not the quantity optimized by the loss.
