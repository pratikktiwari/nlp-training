Chapter 04 / N-gram language model intuition

Guess the next word from the last few words

Until now we learned word vectors. Now we use words to predict the next word, which is what a language model does.

The small examples on this page run in your browser on 10 short sentences. The results in sections 3 to 5 come from the Python script, trained on about 2 million words of Wikipedia.

1. The task: read n − 1 words, guess word n

An n-gram is just n words in a row. We slide a window of n words along the text. The first n − 1 words in the window are what the model gets to read, called the context. The last word is the answer it has to guess, called the target.

Each window becomes one training example. Moving the window one word to the right gives the next example.

<eos> means “end of sentence”. We keep it as a word, so the model also learns where sentences stop, and a window can run from the end of one sentence into the next.

2. Count model: look up what came next before

The simplest model just remembers. For a context such as the cat, it finds every place where the cat appears in the training text, and counts which word came right after it.

Dividing each count by the total turns the counts into probabilities. The guess is the word with the biggest count.

P(next word | context) = (times the context was followed by that word) / (times the context appeared)

What if the context never appeared?

Then there is nothing to count, and every probability would be 0 / 0. Try bird ran above: no sentence has those two words in a row. The script then backs off: it drops the oldest word and looks up only ran. If even one word is unseen, it uses plain word counts, which always exist.

3. A bigger n: sharper guesses, but fewer matches

After the, almost anything can follow. After in the first season of the, far fewer words fit. So more context should help.

The catch: a longer context is less likely to have appeared in the training text at all. Then the count model has to back off, and the extra context is wasted. The table shows this on Wikipedia text the model never trained on.

4. Neural model: let similar words share what they learned

The count model treats every word as a separate symbol. Seeing the cat sat a hundred times teaches it nothing about the dog sat, because dog is a different key in its table.

The neural model replaces each word with an embedding, the same kind of learned vector as in chapter 01. Words used in similar places get similar vectors, so what is learned for cat also moves the guesses for dog. It also never meets an empty count: every context gives some scores.

the · cat→ look up E[the], E[cat]→ join into one list x→ scores = x · W + b→ softmax→ a probability for every word

Training is the loop from chapter 01: compare the probabilities with the real next word using cross-entropy, compute the gradients, and step against them. Only the input changed: instead of one center word, we join n − 1 context words. The math & code page works through one update with every number.

5. Generate text by feeding each guess back in

To write text, we give a starting prompt, predict the next word, add it to the end, and slide the window forward. The new last n − 1 words are the next context. Repeat 60 times.

Greedy always takes the most likely word. Sampled draws a word at random, where a word with probability 0.2 is picked 20% of the time.

Why greedy text repeats forever

The model only ever sees the last n − 1 words. In greedy mode the same context always gives the same next word. So once the last n − 1 words happen to match an earlier moment in the text, everything after that is an exact copy of what followed the first time, and it loops forever.

Sampling breaks the loop because the same context can give a different word. The price is that unlikely words get picked too, so the text drifts. Neither fixes the real limit: the model cannot look further back than n − 1 words, so it cannot keep to one topic. Later chapters remove that limit.

An n-gram model turns “predict the next word” into a lookup (count model) or into chapter 01's softmax with joined embeddings (neural model). More context helps until the context becomes too rare to learn from.
